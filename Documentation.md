# Mini Game Team 5

## Constraints:
The game must be 2-player.
The game must be 30-60 seconds long in play length. (A game may conclude sooner than that.)
Controls (per player): 
One 8-way joystick
2 buttons
Primary action / jump
Secondary action / attack

The game must be developed in 2D

Ideas: 
Fighting Game- Between Two Players. One hit will kill you, so try and avoid attacks while trying to strike back to not die. Possible Draw 
Tag Game- One Player is the Tagger and the other is the Runner. The Runner needs to avoid the Tagger. The Tagger wins if they touch the Runner, while the Runner wins when the Timer runs out. 
Timer is 30 Seconds
1 Time Dash to help avoid opponent (Or Timer for Dash Cooldown)
Physical Obstacles they can run behind
Tagger is Faster than Runner
Runner needs to be strategic about when they use the Dash and the Tagger needs to try and cut them off
