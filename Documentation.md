# Mini Game Team 5

## Game Idea:  
<ul>
<li> Tag Game- One Player is the Tagger and the other is the Runner. The Runner needs to avoid the Tagger. The Tagger wins if they touch the Runner, while the Runner wins when the Timer runs out. </li>
-- Timer is 30 Seconds
-- 1 Time Dash to help avoid opponent (Or Timer for Dash Cooldown)
-- Physical Obstacles they can run behind
-- Tagger is Faster than Runner
-- Runner needs to be strategic about when they use the Dash and the Tagger needs to try and cut them off
</ul>
